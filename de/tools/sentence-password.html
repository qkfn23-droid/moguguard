💡 How does it work?
First Letters: First letter of each word + 숫chars + 특수문chars 조합
Mixed: Compresses sentence with 대소문chars/숫chars/특수문chars 혼합
Leet Speak: Replaces letters with numbers/symbols (a→@, e→3, s→$)
"나는 2024years에 서울에서 살고 있다"
→ 첫글chars: N2e$eSs!
→ 혼합: Na24$eUl#sG
→ Leet: n@2024$30uL!
🧠 Why sentence passwords?
• Easy to remember — Sentences stick better than random strings
• Long and complex — Extraction naturally makes it long
• Only you know — Personal sentences resist dictionary attacks
• Different per site — Add site name for unique passwords
